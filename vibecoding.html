Boss Modeli (Orkestrator)

Boss planlayici model. DeepSeek V3 hizli ve guvenilirdir. R1 daha iyi plan yapar ama yavas ve uzun dusunur (timeout riski).

V3 boss icin hizli ve JSON uretiminde guvenilirdir. R1 uzun dusunur (~90sn+) ve timeout'a takilabilir.

Worker Model Zinciri (Fallback - 6 kademe)

Birincil model basarisiz olursa otomatik olarak sonrakine gecilir. Kredi yetmezse de zincir sonundaki ucretsiz model devreye girer.

Sirayla denenecek: DeepSeek V3 -> Claude 3.5 Sonnet -> Gemini 2.0 Flash -> GPT-4o mini -> Llama 3.3 70B -> Llama 3.2 3B (Free).

Boss Timeout (saniye)

R1 icin en az 300sn onerilir.

Token Limitleri (Genisletilmis Butce v12)

Worker max_tokens modele gore otomatik kirpilir (DeepSeek 8192, GPT-4o 16384). Kesilirse continuation (max 60 tur) + expand (max 8 tur) + buyuk dosyalar icin chunked generation devreye girer.
